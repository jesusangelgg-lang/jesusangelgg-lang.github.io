Catálogo de Etiquetas HTML5 y CSS3

Explora las categorías de etiquetas utilizadas en este proyecto desplegando cada acordeón:

+ Bloques de Estructura
Etiqueta Descripción / Uso
<header> Define la cabecera de la página o sección (títulos, menús de navegación).
<main> Contenedor principal que engloba el contenido central y único del documento.
<section> Agrupa contenido relacionado temáticamente en bloques lógicos.
<footer> Pie de página con información de contacto, derechos o autoría.
+ Etiquetas de Multimedia
Etiqueta Descripción / Uso
<img> Inserta imágenes estáticas con atributos de texto alternativo.
<iframe> Permite incrustar contenido externo, como reproductores de video de YouTube.
<audio> Incorpora pistas de audio con controles nativos de reproducción.
+ Etiquetas de Formularios
Etiqueta Descripción / Uso
<form> Contenedor principal para recopilar datos e inputs del usuario.
<input> Campos interactivos (textos, casillas de verificación, botones de opción).
<select> Crea menús desplegables de selección múltiple o única.
<button> Botones de acción para enviar o restablecer el formulario.
